# Returns & Refunds
_Last updated: March 2025_

- Customers may return any item within **30 days** of delivery for a full refund.
- Opened items are eligible as long as all original accessories are included.
- Refunds go back to the original payment method within 5-7 business days of us receiving the item.
- Return shipping is free; use the prepaid label from the order confirmation email.
- Items damaged by the customer are not eligible for a refund (see Warranty).
